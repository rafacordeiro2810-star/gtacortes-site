# gtacortes-site

- **Cliente:** uso próprio (perfil @gta6.cortado no TikTok).
- **Objetivo:** site mínimo exigido pelo TikTok for Developers para o app "automação" (sandbox gtacortes-teste): página inicial, Termos de Uso e Política de Privacidade.
- **WhatsApp:** n/a.

## Arquivos
`index.html`, `termos.html`, `privacidade.html`, `style.css`. Sem build.

## Como gerar a entrega
Commit e push na branch `main` do repositório `rafacordeiro2810-star/gtacortes-site`; o GitHub Pages publica sozinho.
